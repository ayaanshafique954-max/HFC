HFC Website Concept
===================

Open index.html in a browser.

Before selling/deploying:
1. Confirm the exact outlet, address, phone, opening hours and menu with the owner.
2. Replace the Unsplash food photos with owner-approved restaurant/food photography.
3. Confirm prices and connect the final online-ordering link.
4. Add the owner's logo if available.
5. Add a privacy policy/cookie notice if analytics or tracking is installed.

The site is a responsive single-page HTML/CSS concept and needs no build step.
